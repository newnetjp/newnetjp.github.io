高橋 実来について

筑波大学 情報学群に在籍し、情報学およびセキュリティを専門としています。 本ページでは、プロフィール、経歴、これまでの主な取組・実績、および保有する技術・資格を掲載しています。

基本方針

「知識」は防具にもなれば凶器にもなります。国のセキュリティ教育を経た人間として、 正しい情報をきちんと届けることで人を守れる存在でありたいと考えています。 知識と技術で、人の暮らしを平和に・豊かにする。この方針を活動の基盤としています。

1. プロフィール

原点は東日本大震災です。あの経験から防災や減災、「仕組みを知ること」にずっと関心があります。 小さい頃からドライバーで機械を分解し、中学ではMinecraftのサーバーを立てて運営していました。 コードを書いて何かが動く面白さは、そのあたりで知りました。

根っこにあるのは「なぜそうなっているのか」を考えたい気持ちと、 自分が持っている知識で誰かの暮らしを少しでも安全にしたいという欲求です。 現在は筑波大学で情報学を学びながら、研究と実務を行き来する生活を送っています。

2. 経歴

年ごとの主な活動と、外部からの評価・受賞は次のとおりです。

年表
2012年 – 2020年 探求心の芽生え
震災をきっかけに防災へ関心を持つ。Minecraftサーバーの構築・運営を通じてプログラミングとコミュニティ運営を覚える。学級委員長や図書委員長も経験。
2021年 技術と社会実装
SSH指定中高一貫校に入学し、科学部の研究統括リーダーに就任。株式会社GIRONでアプリケーションエンジニアとして勤務開始。
  • 静岡県ジュニアプログラミングコンテスト 優秀賞
  • SIerロボットアイデア甲子園 全国大会優秀賞
2022年 外部からの評価
国立研究開発法人情報通信研究機構（NICT）のSecHack365に合格。総務省 異能vationアワードにノミネート。自分のアイデアや技術が外の世界で通用する手応えを得た年。
  • SecHack365 合格認定
  • 静岡県児童生徒研究発表会 受賞
2023年 教える側になる
SecHack365修了後、非常勤講師としてUI/UX・表現技法の講義を担当。台湾国家実験研究院CTFでも入賞し、国際的な場での経験を積む。
  • SecHack365 修了・非常勤講師
  • 台湾CTF 入賞
2024年 – 現在 大学と実務の往復
筑波大学 情報学群に進学。山口大学のAKATSUKIプロジェクトに非常勤職員として参加しつつ、スターバックスでバリスタとしても勤務。
今後の予定 次のフェーズ
筑波大学附属病院との共同研究に着手。GMOに学生エンジニアとして参画予定。知識情報・図書館学の領域から、情報と社会の関わりをより深く掘り下げていく。

3. 主な取組・実績

社会課題の解決を目的として取り組んだ、主なプロジェクトを掲載しています。

オープンソース電子カルテシステム

医療インフラが十分でない地域向けの電子カルテです。発展途上国の無医村地域で試験導入を開始しています。医療情報の格差をなくすことを目標としています。

使用技術
Java ／ MySQL ／ AWS

静岡県コロナ対策情報基盤「シズスマ」

新型コロナウイルス感染症の流行初期に、行政に先んじて情報発信基盤を構築しました。アプリとSNSを連携させ、地域の情報格差を埋めることに注力しました。

使用技術
WordPress ／ Firebase ／ Android

openpilot 日本環境最適化

comma.ai社のオープンソース自動運転プロジェクトに参加しました。左側通行・急カーブなど、日本固有の道路環境に対応するためのソフトウェア最適化を担当しています。

使用技術
Java ／ OpenCV ／ OSS
